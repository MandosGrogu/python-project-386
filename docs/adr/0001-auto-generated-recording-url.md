# Автоматическая генерация ссылки на запись

Каждое бронирование обязательно имеет ссылку на запись, хотя сама встреча ещё не состоялась. Решено: ссылка генерируется системой при создании бронирования (случайный slug), не вводится вручную и не меняется при редактировании. Ссылку передают другим участникам встречи для ознакомления — поэтому она нужна сразу при бронировании, а не после звонка.
