# Календарь звонков

Сервис бронирования встреч: клиент видит свободные слоты и оформляет запись, владелец календаря смотрит список предстоящих бронирований. Авторизации нет — один общий календарь, все действия доступны любому посетителю.

## Language

**Слот**:
30-минутный интервал времени в рабочие часы календаря, на который оформляется бронирование.
_Avoid_: таймслот, ячейка, время

**Рабочие часы**:
Пн–пт с 9:00 до 18:00 по московскому времени — период, в котором доступны слоты.
_Avoid_: график, бизнес-часы

**Бронирование**:
Запись клиента на конкретный слот: имя, тема, тип встречи и ссылка на запись.
_Avoid_: встреча, заявка, событие, запись

**Клиент**:
Человек, оформивший бронирование. Указывает только имя, без контактов.
_Avoid_: пользователь, аккаунт, посетитель

**Тип встречи**:
Метка формата бронирования: видеозвонок, аудиозвонок или личная встреча. Ни на что не влияет.
_Avoid_: формат, тип звонка

**Ссылка на запись**:
Обязательная ссылка бронирования. Генерируется автоматически при создании и передаётся другим участникам встречи для ознакомления.
_Avoid_: ссылка на звонок, рекординг

**Владелец календаря**:
Человек, которому принадлежит календарь и который просматривает список предстоящих бронирований.
_Avoid_: администратор, пользователь, менеджер

**Предстоящие бронирования**:
Бронирования, слот которых ещё не наступил. Отображаются на странице владельца.
_Avoid_: будущие, активные
